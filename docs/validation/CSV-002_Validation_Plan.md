## 1. 목적

본 계획서는 Qualytree QMS가 ISO 13485:2016 §4.1.6, GAMP 5 원칙에 따라 의도된 용도에 적합하게 동작함을 체계적으로 확인하기 위한 유효성확인 활동을 계획한다.

## 2. 범위

- 대상 시스템: Qualytree QMS 웹 애플리케이션 (qualy-tree.com)
- 적용 환경: 프로덕션 환경 (Vercel + Supabase Cloud)
- 유효성확인 유형: IQ / OQ / PQ

| 항목 | 분류 |
|------|------|
| 소프트웨어 유형 | 카테고리 4 (Configured Software — Supabase 위에 React 커스텀 로직) |
| 위험 등급 | 중간 (품질 기록 관리, 직접 환자 접촉 없음) |
