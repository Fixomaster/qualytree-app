# CSV-004 운영 적격성 확인 프로토콜 (OQ Protocol)

| 항목 | 내용 |
|------|------|
| 문서번호 | CSV-004 |
| 시스템명 | Qualytree QMS |
| 버전 | 1.0 |

---

## 1. 목적

Qualytree QMS의 각 기능이 설계 사양(URS)에 따라 정상 동작함을 확인한다.

## 2. 테스트 케이스

### OQ-001: 인증·접근 제어 (Critical)

| TC-ID | 테스트 내용 | 기대 결과 | 합격/불합격 |
|-------|------------|-----------|------------|
| OQ-001-01 | 유효한 이메일/비밀번호로 로그인 | 홈 대시보드 이동 | |
| OQ-001-02 | 잘못된 비밀번호 로그인 시도 | 오류 메시지 표시, 접근 거부 | |
| OQ-001-03 | 세션 만료 후 접근 | 로그인 페이지 리다이렉트 | |
| OQ-001-04 | 권한 없는 메뉴 접근 | 접근 거부 또는 미노출 | |

### OQ-002: NCR (부적합보고서) (Critical)

| TC-ID | 테스트 내용 | 기대 결과 | 합격/불합격 |
|-------|------------|-----------|------------|
| OQ-002-01 | 신규 NCR 등록 | DB 저장, 목록 표시 | |
| OQ-002-02 | NCR 상태 변경 (열림→조사중→종결) | 상태 변경 저장 | |
| OQ-002-03 | NCR PDF 출력 | 회사정보 포함 PDF 생성 | |
| OQ-002-04 | NCR 삭제 | 목록에서 제거, 감사 로그 기록 | |

### OQ-003: CAPA (Critical)

| TC-ID | 테스트 내용 | 기대 결과 | 합격/불합격 |
|-------|------------|-----------|------------|
| OQ-003-01 | 신규 CAPA 등록 | DB 저장 | |
| OQ-003-02 | CAPA 효과성 평가 기록 | 필드 저장 | |
| OQ-003-03 | CAPA PDF 출력 | 정상 PDF 생성 | |

### OQ-004: 회사 마스터데이터 (Critical)

| TC-ID | 테스트 내용 | 기대 결과 | 합격/불합격 |
|-------|------------|-----------|------------|
| OQ-004-01 | 회사명 수정 후 NCR PDF 출력 | 수정된 회사명 PDF에 반영 | |
| OQ-004-02 | 사업자번호 입력 후 서류 헤더 확인 | 헤더에 사업자번호 표시 | |

### OQ-005: 감사 추적 (Major)

| TC-ID | 테스트 내용 | 기대 결과 | 합격/불합격 |
|-------|------------|-----------|------------|
| OQ-005-01 | 기록 생성 시 감사 로그 자동 생성 | audit_log 테이블에 삽입 | |
| OQ-005-02 | 감사 로그 수정/삭제 불가 | 오류 반환 (RLS) | |

### OQ-006: 전자서명 (Major)

### OQ-007: PDF 출력 (Major)

| TC-ID | 테스트 내용 | 기대 결과 | 합격/불합격 |
