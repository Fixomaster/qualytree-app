# CSV-005 성능 적격성 확인 프로토콜 (PQ Protocol)

| 항목 | 내용 |
|------|------|

---

## 1. 목적

실제 운영 환경에서 Qualytree QMS가 실제 업무 시나리오를 정확하고 일관되게 처리함을 확인한다.

## 2. 시나리오 테스트

### PQ-001: 부적합 처리 전체 흐름 (End-to-End)

**시나리오**: 생산라인에서 부적합 제품 발견 → NCR 등록 → CAPA 연계 → 종결

| 단계 | 수행 내용 | 기대 결과 | 합격/불합격 |
|------|-----------|-----------|------------|
| 1 | NCR 신규 등록 (부적합 내용, 발견 부서, 제품) | NCR-YYYYMMDD-001 번호 자동 부여 | |
| 2 | NCR 원인조사 기록 입력 | 저장 성공 | |
| 3 | CAPA 연계 등록 | CAPA에 NCR 번호 연결 | |
| 4 | CAPA 조치 완료 기록 | 조치 내용 저장 | |
| 5 | NCR 종결 처리 | 상태 "종결" 변경, 감사 로그 생성 | |
| 6 | NCR PDF 출력 | 전체 처리 이력 포함 PDF | |

### PQ-002: 내부심사 수행 흐름

| 단계 | 수행 내용 | 기대 결과 | 합격/불합격 |
|------|-----------|-----------|------------|
| 1 | 심사 계획 등록 (날짜, 심사원, 부서) | 저장 성공 | |
| 2 | 심사 체크리스트 작성 | 항목별 결과 입력 | |
| 3 | 지적사항 NCR 연계 | NCR 자동 생성 또는 연결 | |
| 4 | 심사 결과 보고서 PDF 출력 | 심사원·날짜·지적사항 포함 | |

### PQ-003: 다중 사용자 동시 접속

| 항목 | 조건 | 기대 결과 | 합격/불합격 |
|------|------|-----------|------------|
| 동시 사용자 | 5명 동시 로그인 | 정상 응답 (< 3초) | |
| 동일 레코드 동시 수정 | 2명이 같은 NCR 편집 | 마지막 저장 우선, 충돌 없음 | |

### PQ-004: 데이터 무결성

| 항목 | 조건 | 기대 결과 | 합격/불합격 |
|------|------|-----------|------------|
| 필수 필드 누락 저장 | 빈 필드로 저장 시도 | 유효성 오류, 저장 차단 | |
| 특수문자 입력 | SQL 인젝션 시도 문자열 | 이스케이프 처리, 저장 성공 | |
| 백업 복구 | 백업 파일로 복구 시도 | 데이터 정합성 유지 | |
